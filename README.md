# 国家の体力は、毎朝の習慣でできている。— では習慣は、何でできているのか。

**LLMマルチエージェントによる「定着」の創発観測**
AIエージェント社会シミュレーションハッカソン Vol.2 提出作品（個人参加：tanaka）

> 誰も「続けろ」と言わない世界に6体のLLM住人を放つ。
> 即時コスト・遅延便益・中断減衰——「習慣」の骨格だけでできた記号世界で、
> 続ける文化は生まれるのか。会話チャネルの有無だけを差し替えて観測した。

## 1. 30秒でわかる結果

| | seed1 | seed2 | seed3 | seed4 | seed5 |
|---|---|---|---|---|---|
| 会話あり（定着率） | 0.167 | 0.833 | 0.667 | 0.500 | 0.833 |
| 会話なし（定着率） | 0.833 | 0.667 | 0.667 | 0.333 | 0.833 |

1. **✅ 認定した創発：「命名された仮説の発生と伝播」**（会話あり**5/5シード** vs 会話なし0/5・Fisher p≈0.004。**脱文脈版・12体版・Haiku版でも再現**）。住人たちは
   誰にも指示されず仮説に名前を付け——「比例仮説」「20説」、住人名をA1〜A6に置換した EXP-007 でも
   「ランダム変動説」——それが集団に定着した。**LLMが人間の物語を再生しただけではないことを実測で確認**
2. **❌ 棄却：seed1の劇的な「会話が定着を食う」逆転は、seed2・4で反転。実験前に登録した基準どおり
   死んだと書いた**（審査の見どころはここです。都合の悪い再現失敗を隠していません）
3. **⚠️ 強い資源勾配「資源の罠」**：回復量1.3以下の個体は84%が脱落（1.5以上は16%・延べ84個体）。
   seed5で反例が出たため「常に最下位」から**勾配へ主張を修正**。個体物理に還元できるため創発とは呼ばない

数値・判定・限界のすべて：[`RESULTS.md`](RESULTS.md)

## 2. 何が創発なのか（主張→根拠→再現）

主張はすべて、根拠ファイルと再現コマンドつきで書く。

| 主張 | 根拠 | 再現 |
|---|---|---|
| プロンプトに社会的な語・指示は一切ない | [`src/prompts.py`](src/prompts.py)（エージェントに渡る文字列の全生成源） | `bash tools/check_condition1.sh` |
| 実験係・仮説の命名・再現プロトコルが自然発生した | [`experiments/EXP-001_会話あり_seed1/logs/messages.jsonl`](experiments/EXP-001_会話あり_seed1/logs/messages.jsonl)（t2, t4, t26） | `python3 tools/vocab.py <messages.jsonl>` |
| 会話の有無で定着が逆転する | 各実験の `logs/metrics.json` | `python3 src/main.py --config experiments/EXP-001_会話あり_seed1/config.yaml` |
| 判定は事前登録した基準に従った | [`experiments/EXP-001_会話あり_seed1/所見.md`](experiments/EXP-001_会話あり_seed1/所見.md)（P2判定の事前登録） | — |

創発の判定枠組み（非記述性・マクロ性・再現性・**非模倣性**の4条件）は [`docs/02_観測設計.md`](docs/02_観測設計.md)。
本実験は**ベース世界を最初から無意味な記号だけで作る**ことで、条件4（LLMが人間社会を思い出しただけではないこと）を設計に織り込んでいる（[`docs/01_世界設計.md`](docs/01_世界設計.md) 5章）。

## 3. 世界の設計（要旨）

**物理は設計する。社会は設計しない。**（[`docs/ADR/ADR-003_仮説検証型を捨てて発見型にする.md`](docs/ADR/ADR-003_仮説検証型を捨てて発見型にする.md)）

- 行動 `A`：エネルギー4を即時消費。続けると**遅れて**回復量が増える（住人には教えない）。中断で蓄積は減衰
- 行動 `rest`：消費なし
- 会話：全員が読める共有チャット（実験条件でON/OFF）。**他者の行動・数値は会話でしか知れない**
- 住人はLLM（Claude Sonnet 5）。**1住人1ターン＝1回の独立プロセス**で、内心は共有されない

全定義：[`docs/01_世界設計.md`](docs/01_世界設計.md)／問いの選定経緯：[`docs/00_問い.md`](docs/00_問い.md)

## 4. 実行方法

```bash
git clone https://github.com/kyomei-community/hackathon.git && cd hackathon
python3 -m venv .venv && .venv/bin/pip install pyyaml matplotlib imageio-ffmpeg
# 要: claude CLI（Claude Code）にログイン済みであること。エージェントの頭脳として claude -p を呼ぶ
.venv/bin/python src/main.py --config experiments/EXP-000_smoke/config.yaml   # 動作確認（2体×3ターン・数十円相当）
.venv/bin/python src/main.py --config experiments/EXP-001_会話あり_seed1/config.yaml  # 本番条件の再実行
.venv/bin/python tools/analyze.py experiments/EXP-001_会話あり_seed1          # 図の生成
.venv/bin/python tools/make_video.py out.mp4                                  # デモ動画の再生成
```

- LLMは非決定的なため個々の発話は再現しない。**主張の対象はマクロ現象**で、独立3runの方向一致を再現とする（[`docs/01_世界設計.md`](docs/01_世界設計.md) 7章）
- 各実験の config・seed・全ログはコミット済み。コストはconfigの `cost_limit_usd` で自動打ち切り

## 5. プロダクト：制度サンドボックス

> **「この制度を入れたら、人の集団に何が起きるか」を、入れる前に試せる場所。**

会話チャネルON/OFFは、実在サービス**セカプラ**（50代からの伴走サービス）の
「コミュニティは継続を生む」という中心仮説の検証そのもの。導入前に得られた知見を、**強さの順に正直に**：

1. **資源の罠（8/8で再現）**：資源が乏しい個体は、努力の意思と無関係に複利の起動（連続実行）に届かない。
   → 伴走の第一の役割は「最初の連続数日」を支えること
2. **リスクモードの発見（3シード中1回）**：seed1では情報交換に特化した集団が形成され、定着率が0.167まで落ちた。
   一般効果としては**棄却済み**だが、「コミュニティが調査の場に固定化すると実践が死ぬ」という
   **失敗モードが実在する**ことはログで示された。→ 実践共有型（もくもく会型）への設計は、このリスクへのヘッジ仮説として検証する価値がある
3. **語彙の自己組織化（4/4で再現）**：会話のある集団は必ず独自の共通語を発達させる。コミュニティの健全性の観測指標になりうる

詳細：[`docs/03_プロダクト構想.md`](docs/03_プロダクト構想.md)

**拡張の現状を正直に分ける**：config だけで変えられるもの＝物理パラメータ・住人数と名前・ターン数・
会話ON/OFF・モデル・コスト上限（EXP-007は住人名の置換だけで作った実例）。
コード変更が要るもの＝新しい行動の追加・開示レベル・チャネル構造（`src/world.py`/`src/prompts.py` の改修）。
LLMの差し替えは [`src/llm_client.py`](src/llm_client.py) 1ファイルに閉じている。
