## ★ 確定した問い（2026-08-25）

> ## 「国家の体力は、毎朝の習慣でできている。では習慣は、何でできているのか。」
>
> 誰も「続けろ」と言わない世界で、続く集団は何を発明するのか。
> その発明を特定し、消して、また生やす。
> そして定着率の差を、日本の医療費・労働生産性に換算して国のスケールで示す。

- 掛け合わせ：**習慣（最小の領域）× 国家の体力（最大の領域）**。主催の「領域の掛け合わせ」の最小×最大ペア。
  「物語が軍事の上流に立つ」と同じ構文で**「習慣が国家財政の上流に立つ」**と言う
- 型：**発見型**。「ルール1個を事前に差し替える」旧型（下記案A〜D）から転換（`ADR-003`）

### 設計原則：物理は設計する。社会は設計しない

- **設計するもの（物理）**：実践には毎日コストがかかる／効果は遅れて出る／会話はできる。
  この圧力構造は精密に作り、config で数値管理する
- **設計しないもの（社会）**：「仲間」「励まし」「報告」「見える化」「習慣」という語も仕組みも
  一切プロンプトに書かない。**続ける文化が生まれるかどうか自体が観測対象**
- Vol.1採点基準A「精密な世界ルール × 生データのみのエージェント入力」（Vol.1公開ルーブリック）の理想形を狙う

### 3フェーズ

| フェーズ | 日程 | 何をするか |
|---|---|---|
| **P1 発見** | 〜8/26 | 最小世界を回し、**何が生まれるか観る**（報告の儀式？ペア形成？語彙の定着？）。事前に縛るのは指標と判定手続きのみ（`02_観測設計.md`） |
| **P2 検証** | 8/27-28 | 生まれた要因Xを**後から**アブレーション（消して定着が崩れるか）＋3シード＋脱文脈テスト |
| **P3 換算** | 8/28-29 | 条件間の定着率の差を、公的統計で日本経済インパクト（円）に換算 |

### 保険：会話チャネル ON/OFF

P1で何も生まれないリスクに備え、**会話の可否**だけは条件として最初から持つ。
社会構造を何も前提しない最中立の比較で、①何が生まれてもP2のアブレーション土台に流用でき、
②何も生まれなくても「孤立した個体は習慣を維持できるか」という結果が残る。

### 換算層（P3）— 株価には換算しない

- **日経平均等への接続はしない。** 株価は金融政策・海外要因が支配し、因果連鎖が長すぎて反証不能。
  AI評価者は「主張と証拠の対応」を読むため、根拠の薄い接続は信頼性の失点になる
- 採る経路は**因果連鎖が短く、各リンクに公的統計がある**もの：
  `定着率の差 → 生活習慣病リスク → ①医療費（国民医療費の生活習慣病分）＋②労働生産性（プレゼンティーイズム損失） → 年間◯兆円（楽観/保守の幅つき）`
- **換算はシミュレーションではない。決定論的な計算式であり、そう明記する**（作業規約「実験結果を創作しない」）。
  係数は P3 で出典付きで確定する

### なぜこの問いか

- **①面白さ**：安保の語法で日常を語る転倒。「国家の体力は習慣でできている」は続きを聞きたくなる
- **②創発**：社会の仕組みを一切書かずに定着の文化が生まれたら、それは設計していない秩序そのもの。
  4条件（特に条件4）の検証が最初から織り込まれている
- **③プロダクト化**：セカプラの中核「知る→実践する→定着する」の"定着"を作る要因を、導入前に実験で特定できる装置。
  もし報告儀式が自然発生したら、現実のセカプラの「もくもく作業会」と同型＝実サービスの現象の再現
- **Kyomei線**：発見された維持要因は、コミュニティ設計（何を可視化するか・伴走をいつ外すか）の実パラメータになる

## 1. 案A：出所が消せない世界

**問い：情報の出所が完全に追跡できる世界で、噂は消えるのか、形を変えるのか。**

| 項目 | 内容 |
|---|---|
| 差し替えるルール | すべての発言に「誰から聞いたか」の連鎖が自動で付き、改竄も削除もできない |
| 創発の仮説 | ①発言の萎縮（誰も一次情報を言わなくなる）②伝聞の分業（出所をぼかす中継役が自然発生）③「私は聞いていない」型の定型句の発明 |
| 最小実験 | エージェント5体・10ターン。1体だけに偽の情報を渡し、伝播の形を追跡連鎖ありなしで比較 |
| 観測できる量 | 伝播の深さ／一次発言の減少率／出所を明示しない発言の割合 |
| プロダクト化 | SNS・社内チャットの「機能を入れる前に副作用を見る」テストベッド |
| 弱点 | 「萎縮する」で終わると当たり前。②③が出るかが勝負 |

## 2. 案B：評判が有限な世界

**問い：称賛が有限資源になったとき、協力は増えるのか、潰し合いになるのか。**

| 項目 | 内容 |
|---|---|
| 差し替えるルール | コミュニティ全体の信用の総量が固定。誰かの信用が上がれば、必ず他の誰かが下がる |
| 創発の仮説 | ①相互称賛カルテル（少数で信用を回し合う）②新参者の排除 ③信用の「贈与」による恩義の連鎖 |
| 最小実験 | エージェント5体・10ターン。信用総量=固定 と 無制限 で、称賛の宛先分布を比較 |
| 観測できる量 | 称賛のジニ係数／相互称賛ペアの数／新規参入者が信用を得るまでのターン数 |
| プロダクト化 | 相対評価の人事制度、コミュニティのトークン設計を導入前に試す |
| 弱点 | ゼロサムなら格差が出るのは自明。**カルテルが自然発生するか**が観測の焦点 |

## 3. 案C：忘れる世界

**問い：何を記録するかを各自が選べるとき、共同体の「歴史」は誰のものになるか。**

| 項目 | 内容 |
|---|---|
| 差し替えるルール | 記憶はターン経過で減衰する。ただし「書き残した」ものだけが残る。書く行為にはコストがある |
| 創発の仮説 | ①記録係という役割の自然発生 ②記録の偏りがやがて「定説」になる ③口伝の儀式化（毎ターン繰り返される定型句） |
| 最小実験 | エージェント5体・15ターン。減衰あり／なしで、共有される事実の一致度を比較 |
| 観測できる量 | 記録行為の回数と偏り／終盤に全員が共有している事実の数／原型からの改変度 |
| プロダクト化 | 組織のナレッジマネジメント、議事録文化の設計 |
| 弱点 | ターン数が要る（減衰が効くまで時間がかかる）＝コストが3案で一番高い |

## 4. 案D：断定できない専門家の世界 ★推奨

**問い：専門家が断定を禁じられた世界で、素人たちは何を根拠に決めるのか。**

| 項目 | 内容 |
|---|---|
| 差し替えるルール | 集団に「知識はあるが断定を禁じられた専門家」が1体いる。他は知識のない参加者で、全員が決断を迫られている |
| 創発の仮説 | ①参加者の中から**非公式の権威**が立ち上がる（体験談を語る者が専門家より強い影響力を持つ）②専門家の一般論が、伝言される過程で**断定形に変質する** ③「〜らしいですよ」型の責任回避構文が集団に定着する |
| 最小実験 | 5体・10ターン。専門家の断定禁止 ON/OFF で、影響力の分布と発話の断定度を比較 |
| 観測できる量 | 語彙の定着（誰の言い回しが広がったか）／連鎖の深さ（専門家の一言が何ホップ先で断定に変わるか）／発話の断定度の推移 |
| プロダクト化 | **セカプラそのもの。** FPはコンプラ上、具体的な投資先を断定できない。会員は決断したい。その空白を会員同士の口コミが埋めるかどうかは、成長エンジンでもありリスクでもある |
| 条件4への耐性 | **強い。** 「専門家／素人」を「ノードX／ノードY」、「投資」を「操作α」に置換しても、断定の非対称という力学は残る。役割演技に還元されにくい |

**推奨理由：3つの審査軸と Kyomei線が、1つの問いで同時に立つ。**

- ①面白さ：「専門家が断定できないとき、権威はどこから生まれるか」は、続きを聞きたくなる
- ②創発：非公式権威の発生も、伝言の断定化も、プロンプトに書かない。集団構造として立ち上がる
- ③プロダクト化：後付けの作文でなく、Kyomei が実際に運用している制度の話になる
- Kyomei線：会員同士の交流をどこまで開くか、という**実在の設計判断**に答えが出る

**弱点：** 「専門家の権威が落ちる」で終わると凡庸。②の**伝言の断定化**（誰が、どの地点で言い切りに変えたか）を
連鎖グラフ上で特定できるかどうかが勝負どころ。ここは可視化が効く。
