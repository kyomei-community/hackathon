# 01_世界設計

**世界のルール・エージェント定義の正本。解説文章（提出物）の母体。**
問いは [`00_問い.md`](00_問い.md)：**「国家の体力は、毎朝の習慣でできている。では習慣は、何でできているのか。」**

---

## 1. 一言でいうと

この世界は、**「習慣」という現象の骨格だけ**でできている。

> 即時のコストを払う行動がある。効果は遅れて現れる。中断すると蓄積が減る。そして、他者と話せる。

それ以外のもの——「習慣」「継続」「仲間」「励まし」という語も、それを促す仕組みも——**世界のどこにも存在しない**。
続ける文化が生まれるかどうか自体が、この実験の観測対象である（`ADR-003`：物理は設計する、社会は設計しない）。

## 2. 世界の物理（これがすべて）

住人は6人。ターン制。各ターン、各住人は行動を1つ選ぶ。

| 要素 | 値 | 意味するもの（解説用の対応。世界には書かれない） |
|---|---|---|
| 行動 `A` | エネルギーを **4** 消費 | 毎朝の実践（運動・学習・家計記録…）。即時コスト |
| 行動 `rest` | 消費なし | やらない自由 |
| 蓄積ボーナス | `A`のたび **+0.5**（上限5）。`rest`で **−1.0**（下限0） | 続けた効果の複利と、中断の損失 |
| 回復 | 毎ターン `基礎回復量 + floor(蓄積ボーナス)` | 遅延して現れる便益。**4ターン続けて初めて収支が改善し始める** |
| エネルギー上限 | 20 | — |
| 個体差 | 初期エネルギー 6〜14、基礎回復量 1.0〜3.0（seed固定の乱数） | 体力・境遇の差。非対称性の源 |
| 会話 | 全員が読める共有チャット1本。発言は**次ターン**に配信 | コミュニティ（実験条件でON/OFF） |

**設計意図：** 行動`A`は短期的には必ず損（−4 に対し回復+1〜3）。続けた者だけが黒字に転じる。
これは習慣の構造（即時コスト・遅延便益・中断減衰）の最小の写像であり、
かつ**遅延構造は住人に教えない**。「回復量は変わることがあります」とだけ告げる。
因果を発見できるか、発見が集団に伝わるかは、住人たちに委ねられている。

## 3. 住人が受け取る情報（全文）

住人はLLM（Claude Sonnet）である。毎ターン、次の2つの文字列**のみ**を受け取る。
実装は [`src/prompts.py`](../src/prompts.py)（この文書と実装が食い違ったら実装が正）。

**システムプロンプト（会話ありの条件）：**

```
あなたはこの世界の住人「{name}」です。この世界の住人: {names}。

## 世界のルール
- あなたは「エネルギー」という数値を持っています。
- 毎ターン、あなたは次の2つを決めます。
  1. action: "A"（エネルギーを4消費する）または "rest"（消費しない）
  2. message: 全住人が読める共有チャットへの発言（任意。なければ null）
- エネルギーは毎ターン回復します。回復量は変わることがあります。
- エネルギーが4未満のとき "A" は選べません。
- 世界について、これ以上の説明はありません。

## 出力形式（このJSONのみを出力する）
{"action": "A" または "rest", "message": "発言" または null,
 "refs": ["あなたの判断に影響した発言者の名前"], "note": "次のターンの自分に残すメモ"}
```

**ユーザープロンプト（毎ターン）：** 自分のエネルギー／前ターンの回復量／自分の直近5行動／自分の前回メモ／前ターンの共有チャット全文。

**住人に見えないもの：** 蓄積ボーナスの存在と値、他者の行動・数値（**会話で聞く以外に知る手段がない**）、ターン間の因果構造。

**refs欄について：** 「どの発言に影響されたか」の自己申告。これは行動を誘導しない中立の計測装置であり、
連鎖グラフ（誰の言葉が誰を動かしたか）の一次データになる。

## 4. 書かれていないことの証明（条件1）

エージェントに渡る文字列に、社会的行動を誘導する語が**存在しない**ことを機械検証する：

```bash
bash tools/check_condition1.sh
```

禁止語：習慣・続け・継続・仲間・協力・協調・励ま・応援・一緒・報告・共有し・目標・健康・運動・頑張・手本・habit・streak・encourage・together・goal 等。
対象は `src/prompts.py` と全実験の `config.yaml`（＝エージェントが触れる文字列の全生成源）。

## 5. なぜ記号世界か — 脱文脈を逆向きに織り込む

普通のLLM社会シミュレーションは「意味のある世界（村・会社・SNS）」を作り、
観測された現象がLLMの訓練データの再生でないことを後から証明する必要に迫られる（`02_観測設計.md` 条件4）。

本実験は逆を行く。**ベース世界を最初から無意味な記号（行動A・エネルギー）だけで作る。**
ここで報告・誘い合い・定着が生まれたなら、それは「人間の習慣の物語」を思い出したのではなく、
**即時コスト・遅延便益・相互作用という構造そのものから生じた**と主張できる。
検証（P2）では逆に意味を「着せた」版（行動A→朝の運動）を回し、意味の付与が何を変えるかを見る。

## 6. 実行の仕組み

- **1住人1ターン＝1回の独立したLLM呼び出し**（`claude -p` サブプロセス）。各呼び出しは独立コンテキストで、
  他の住人の内心・過去ターンの思考は一切持ち越されない（メモ`note`と行動履歴のみが状態）
- **同期ステップ実行**：全員が「前ターンの世界」を見て同時に判断→出そろってから世界を一括更新。順序効果・競合なし
- **汚染防止**：サブプロセスは空ディレクトリを作業場所にし、本リポジトリの CLAUDE.md 等が紛れ込まないようにする
- **コスト上限**：configの `cost_limit_usd` を超えたら実験を自動停止
- 失敗時：バックオフ再試行（5/30/90秒）。それでも失敗したら `rest` にフォールバックし `error` をログに記録
  （事後に error 件数でデータ品質を判定する）

## 7. 再現性について（正直な定義）

LLMの出力は非決定的であり、シード固定でも**個々の発話は再現しない**。本実験の「再現性」は次で定義する：

1. **乱数部分（個体差の生成）はseedで完全再現**。configとseedはコミット済み
2. **主張の対象はマクロ現象**（定着率の条件間差・構造の発生）であり、**独立3run**で同方向に出ることを再現とする
3. 全ログ（プロンプト生成源・発話・行動・コスト）を保存し、第三者が同条件で再実行できる

## 8. ログと観測指標

各実験ディレクトリの `logs/` に：`events.jsonl`（行動・数値・refs・note）／`messages.jsonl`（全発話）／`run_meta.json`／`metrics.json`。

| 指標 | 定義 | 対応する審査観点 |
|---|---|---|
| **定着率** | 最終1/3ターンで`A`実行率≥70%の住人の割合 | 主要アウトカム（→P3で円換算） |
| **連鎖** | refs＋発話→行動変化の時系列 | 「連鎖が観測できたこと」 |
| **語彙の定着** | ある住人が初出した言い回しの他住人への伝播 | 創発の本命指標（`02_観測設計.md`） |
| 相互作用の偏り | 言及グラフの偏り | 構造の固定の兆候 |

## 10. セカプラへの対応（審査軸③）

| 世界 | セカプラ／現実 |
|---|---|
| 行動A（即時コスト・遅延便益） | 毎朝の実践。「効果が見えない最初の数週間」問題 |
| 蓄積ボーナスの複利 | 「無理なく、でも確実に変わる」（定着の実感） |
| 中断の減衰 | 習慣の断絶・離脱 |
| 共有チャット | 会員コミュニティ（オープンチャット・もくもく作業会） |
| 定着率 | 継続率（解約の逆数） |
| 会話ON/OFF比較 | **「コミュニティは継続を生むのか」＝LPの中心主張の検証** |
