# ADR-001：世界の豊かさより「証拠密度」を優先する

| 項目 | 内容 |
|---|---|
| 日付 | 2026-08-24 |
| 状態 | 採択 |
| 決定者 | 個人参加（tanaka） |

## 背景

3.5週間・個人参加・API課金という制約下で、審査軸②「連鎖・創発が観測できたこと」をどう取りに行くか。

デフォルトの発想は「豊かな世界を作り、そこで何が起きるか見る」である。
これは**宝くじ**になる。世界が複雑なほど何かは起きるが、
起きたことが①ルールに書いていないこと ②集団の性質 ③再現すること ④LLMの模倣でないこと
（`02_観測設計.md` の4条件）を満たすかは、検証工数の問題であって世界の豊かさの問題ではない。

そして検証工数は、世界が複雑になるほど**増える**。豊かさへの投資は、証拠への投資を食う。

## 決定

**構造を逆にする。**

1. 先に、確実に生産・測定できるマクロ現象を1つ選ぶ（本命：**語彙の定着** — ある個体が発した語が集団に広がる）
2. その現象が出る**最小の世界**を作る。それ以上は作らない
3. 浮いた時間の全部を、**アブレーション・3シード再現・脱文脈テスト**に注ぐ

## 理由

- **4条件を全部検証した作品は、まず他に出てこない。** 特に条件4（脱文脈テスト＝意味を剥いでも同じ構造が出るか）は、LLM社会シミュレーション固有の弱点を正面から潰す手続きであり、ここが差別化点になる
- 本大会は**Claudeベースの AI 評価エージェント**が審査に入る。AIは「世界観の壮大さ」より**主張と証拠の対応**を正確に読む。検証済みの小さな主張は、未検証の大きな主張に勝つ
- 世界を小さく保つことは、そのままAPIコストの上限になる（リスク表の最大項目）

## 結果として受け入れるもの

- 世界設定は地味になる。「壮大な文明シミュレーション」ではなくなる
- 面白さの負荷は**問いの立て方**（審査軸①）に全部乗る。世界の複雑さで面白がらせる逃げ道を捨てる

## 却下した案

- **豊かな世界を作ってから創発を探す**：検証工数が読めず、D-4の機能凍結に間に合わない確率が高い
- **エージェント数を増やして創発確率を上げる**：コストが線形以上に増え、かつ再現実験（3シード×アブレーション×脱文脈）の回数が確保できなくなる。**再現できない創発は創発ではない**
