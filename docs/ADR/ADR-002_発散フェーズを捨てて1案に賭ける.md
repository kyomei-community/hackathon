# ADR-002：発散フェーズを捨てて1案に賭ける

| 項目 | 内容 |
|---|---|
| 日付 | 2026-08-24（JST） |
| 状態 | 採択 |
| 決定者 | 個人参加（tanaka） |

## 背景

締切が 2026-08-30 と判明した（**【要確認】**：記憶ベース。公式確認が必要）。
起案時に想定していた 3.5週間ではなく、**残り6日**。

当初計画（`ADR-001` 起案時）は管理体制の原則に従い、
「問いを3案出し、各案を最低1回は実際に動かしてから選ぶ（机上で選ばない）」を採っていた。

## 決定

**発散フェーズを捨てる。8/24 の時点で問いを1本に確定し、残り全部を証拠に注ぐ。**

## 理由

6日で3案を回すと、内訳はこうなる：

- 3案 × 最小実験 = 実質2日（装置づくりと同時進行なので実際はもっと食う）
- 残り4日で、確定案の条件振り・3シード再現・アブレーション・脱文脈テスト・動画・文章

これは**どれも中途半端に終わる形**である。
そして `ADR-001` で決めた通り、この大会で効くのは世界の豊かさではなく**証拠密度**。
証拠に注げる日数を2日削ってまで、選定の精度を上げる価値はない。

**「机上で選ぶな」という原則を、意図的に破っている。** 破る以上、代償を明示しておく：
選んだ問いが外れだった場合、リカバリーの時間は無い。この賭けは 8/24 に閉じる。

## 選定を机上で行うための代替根拠

実験の代わりに、次の2つを選定根拠とする。

1. **創発4条件（`02_観測設計.md`）に照らして、条件4（非模倣性）に耐えるか**
   — LLM が人間社会の型を再生するだけで終わる問いを落とす
2. **Kyomei の実事業（セカプラ）の意思決定と同型か**
   — 審査軸③が後付けの作文でなく実物になる。かつ大会後に資産が残る（`03_プロダクト構想.md`）

## 結果として受け入れるもの

- 問いの選定が経験的に裏付けられていない。解説文章では**そう正直に書く**
  （「3案を比較して選んだ」と書かない。無かった比較を書くのは作業規約「実験結果を創作しない」への違反）
- 落とした案は `00_問い.md` に残す。捨てた記録も資産
