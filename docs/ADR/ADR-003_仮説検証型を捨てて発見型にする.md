# ADR-003：仮説検証型を捨てて発見型にする（問いの確定）

## 決定

問いを次の1本に確定する（`ADR-002` の 8/24 ゲートを1日超過しての確定）。

> **「国家の体力は、毎朝の習慣でできている。では習慣は、何でできているのか。」**

同時に、実験の型を**仮説検証型**（ルール1個を事前に差し替えて ON/OFF 比較）から
**発見型**（最小の圧力構造だけを設計し、維持の仕組みが生まれるのを観測してから後追いで検証）に転換する。

## 背景

1. 8/24〜25 に大会側の一次情報（公式サイト・Vol.1公開ルーブリック）を確認した。
   Vol.1 採点基準Aの理想は「行動戦略を完全に LLM の判断に委ねる」であり、
   優勝2作はどちらも社会的な仕組みをトグルせず、環境圧のみ設計して協調の**発生**を観測していた
2. ユーザーの指摘：「習慣化の要素（例：脱落の可視性）をこちらが最初から決めると、
   見える/見えないの世界自体を決めてしまい、本来の創発は生まれないのではないか」
   —— 仮説検証型は「可視性が効く」という仮説の確認であって、創発の発見ではない。この指摘を採用した
3. Kyomei 側の要望：「習慣化の要因を特定したい」「最終的に日本経済へのインパクトにつなげたい」

## 設計の線引き：物理は設計する、社会は設計しない

「何も設計しない」と創発は出ない（圧力のない世界では雑談して終わる）。
Vol.1 優勝作が設計していたのはバッテリー経済等の**物理**であり、協力という**社会**ではない。
本プロジェクトも同じ線を引く。

- 設計する：実践のコスト・遅延する効果・会話チャネル（config で数値管理）
- 設計しない：仲間・励まし・報告・見える化・習慣という語と仕組み（grep で不在を証明する＝条件1）

## 換算層の選択：株価ではなく医療費・労働生産性

「日経が上がる/下がる」への接続は検討のうえ却下した。

- 株価は金融政策・海外要因が支配的で、習慣からの因果連鎖が長すぎて反証不能
- AI 評価者は主張と証拠の対応を読む。根拠の薄い接続は加点でなく信頼性の失点になる
- 医療費（国民医療費の生活習慣病分）と労働生産性（プレゼンティーイズム損失）は
  因果連鎖が短く、各リンクに公的統計・先行研究がある。円換算で「年間◯兆円」という
  分かりやすい1つの数字が出せる。「日本経済へのインパクト」はこの形で示す
- 換算は決定論的な計算式であり、シミュレーションと呼ばない（作業規約「実験結果を創作しない」）

## 事前登録との整合

発見型では現象を事前に指定できないため、事前登録の対象を再定義した（`02_観測設計.md` に反映済み）。

- **P1（発見）**で縛るもの：観測指標（定着率・相互作用グラフ・語彙定着）と判定手続き（4条件）
- **P2（検証）**で縛るもの：実験カードに「①何が出たら創発と呼ぶか ②何が出たら仮説は死ぬか」を実行前に書く（従来どおり）

## リスクと保険

- **P1 で何も生まれない**：会話チャネル ON/OFF だけは最初から条件に持つ（社会構造を前提しない最中立の比較。
  何が生まれてもアブレーションの土台に流用でき、生まれなくても null result として正直に書ける）
- **発見が「LLM が知る人間社会の再生」にすぎない**：条件4（脱文脈テスト）は最後まで捨てない
  （`プロジェクト管理体制.md` 4.1.1 の切り捨て順のとおり）

## 却下した案（発想は `00_問い.md` に記録を残す）

- **案X（脱落の可視性 ON/OFF）・案Y（伴走者の途中退場）**：問いとしては強いが仮説検証型。
  発想は P2 のアブレーション条件の候補として温存する
- **案Z（断定できない専門家＝旧案D）**：現行サービス定義（禁止事項4・7・8）で構造の実在は再確認できたが、
  「習慣化を研究する」という本プロジェクトの目的から外れるため見送り
- **安全保障を直接テーマにする案**：Vol.1 で既出（my-social-agents、創発設計 7.5）。
  「安保をテーマにする」のではなく**「安保の語法で習慣を語る」**方を採る
